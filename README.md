# odin-recipes
My First HTML Project

This project is a basic HTML website created as part of The Odin Project.

The goal of this project is to practice the fundamentals of HTML and learn how to structure a webpage using elements such as headings, paragraphs, links, images, and lists.

By completing this project, I will demonstrate my ability to:

Create and structure an HTML document (odin-recipes)
* Use common HTML elements
* Create links and add images
* Organize content using lists
* Work with files and folders
* Use Git and GitHub to track and publish my work
